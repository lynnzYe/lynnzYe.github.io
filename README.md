# Linzan Ye

Linzan Ye's personal website. Built with Vite + React + Typescript.


## Deploy
- serve: `npm run deploy`
- dev: `npm run dev`
- update projects:
    1. add the project to Projects.tsx
    2. create a tsx page for the new project
