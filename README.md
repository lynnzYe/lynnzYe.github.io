# Linzan Ye

Linzan Ye's personal website. Built with Vite + React + Typescript.

## Deploy

- serve: `npm run deploy`
- dev: `npm run dev`
- update projects:
  1. add the project to Projects.tsx (don't forget to add to the list below)
  2. create a tsx page for the new project
  3. Update ProjectRoutes
